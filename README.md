# Tu-Taco

A simple website that uses UTC to calculate whether or not an on-campus dining location is open. 

## Usage
Simply visit [istutacoopen.com](https://istutacoopen.com)

## Contributing

Pull requests are welcome. For major changes, please open an issue first
to discuss what you would like to change.

We are currently looking into Grubhub integrations for more accurate results and features.
